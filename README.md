# Curio

一个陪孩子从小学三年级用到高中的理科探索平台，覆盖数学、物理、化学、生物。家庭自用。

孩子是飞船舰长，知识点是待登陆的星球。在星图上探索，在知识地铁上看清楚每个大概念是怎么从一年级一路通到高中的。做实验时先猜、再看、再解释。

界面里不出现「学习」二字。

## 现在的状态（2026-11-28）

- **正式外壳已经在用**：星图、知识地铁、知识索引、选领航员（小灯、小环）、明暗切换和声音开关。设备上的记录算数，导出和恢复在 2026-11-14 演练通过。
- **能玩的内容**：数学「0 和 1 之间」19 颗星和分配律「掰巧克力」，生命「生命的说明书」3 项活动。物理杠杆 v3 被打回，v4 在重新设计。
- **共用零件库** `kit/`：画风、圆钮、分数、手绘线、宿主通信和程序化微音效只有一个出处，按版本冻结（ADR-011）。
- **还没做**：问领航员（AI 问答，中转服务已部署）、维修舱（错题本）、今日航线（打卡）。

做到哪、下一步做什么，以 [`docs/handoff.md`](docs/handoff.md) 第 4 节和 issue [#13](https://github.com/deepnorth2077/Curio/issues/13) 为准，这里只写个大概。

## 分工

- **Luka**：产品负责人。拍板、部署、验收，组织舰长试玩。不写代码。
- **维护者**：Luka 指定的模型，负责设计、整合和 git 操作。Claude 负责架构、规格、活动设计和最后的审查；实现可以交给别的模型（Claude 子 agent、Codex、Antigravity 等），按 `AGENTS.md`「协作方式」开分支、开 PR，CI 通过才合入。
- **不能省的**：不直接推 `main`；改存下来的数据格式、科学事实要另一方独立审；不为了让交付通过而放宽规格或测试。

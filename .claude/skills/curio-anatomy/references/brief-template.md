# 动手探索设计说明

由设计者填写。实现者拿到的是已经审过的原稿。用自己的文字写清同一颗星怎样开场、孩子能摆出哪几种结果、最后带走什么。写题目、选项、台词原句和可复算的数字。需要看成稿时，可对照掰巧克力的逐站脚本和切分机的验收用例。

「实现」里的两行是格式示例。回到 [经验清单的实现一节](lessons.md#实现) 选出本星确实用得到的编号，每行一个。与本星有关的尺寸、台词、反馈和动作直接写在相应的站里。

交设计审查时附上知识点卡和配套挑战草稿。知识点卡的目标写成孩子可以做出的动作，列出至少三种彼此不同、能从实际回答区分的误区。确认实验和挑战面向同一年龄段。通过后交实现者按原稿实现 `manifest.yaml` 和 `index.html`，使用 `starter.html` 的契约与共用画风。独立验收者按表先写走查。实现者跑走查并查看三端截图，将实物、星卡和末题交给另一位审查者实际试玩。

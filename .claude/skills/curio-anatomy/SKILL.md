# 好奇号 · 知识的解剖

改编自 wheresryan22/anatomy（MIT）。原版把技术概念做成等距机械图；这里是给 8 到 17 岁孩子用的简化版，画风换成 Claude 的暖纸面和墨线。

## 唯一要记住的一句话

**实物就是解释。** 不要写「X 是 Y」再配一张图，再出三道选择题。要发明一个孩子能亲手摆弄的东西，让它的运转本身就是这个知识。孩子看懂这个东西是怎么动的，也就懂了这个知识。

| 知识 | 实物（孩子亲手做的事） |
| --- | --- |
| 2 米长的 DNA 怎么收进细胞核 | 一台绕线机：摇把手，把线绕上小线轴、盘起来、折成环，读数显示缩短了多少倍 |
| 46 条染色体两两成对 | 一张配对台：显微镜下散着 46 根小短棒，按长短和条纹配对，配好一对就揭晓哪根来自爸爸 |
| 小孔成像为什么是倒的 | 一个暗箱：拖动蜡烛、调孔的大小，屏上的像跟着翻转、变亮或变糊 |
| 分数的大小 | 一台切蛋糕机：转刻度盘决定切几份，同样的一份越切越小 |
| 浮力 | 一个水槽：把东西按下去再松手，看浮起来的速度和露出水面多少 |

做不出来的三种样子，都见过：
- **太抽象**：方框、箭头、文字卡片。孩子认不出它是什么东西。
- **太平**：一张静态图加一句话。没有可动的部分，没有可发现的东西。
- **假互动**：点「继续」、点选项都不算动手。动手是指孩子的动作改变了实物的状态，读数跟着变。

## 工作顺序

先写下面 1 到 5，再动手画、写代码。质量大部分在这一步就定了。

1. **找谜题。** 把驱动问题改成一个让人想问「怎么可能？」的矛盾。不要问「染色体是什么」，要问「2 米长的线，怎么收进一个比针尖还小得多的球里，还不打结？」谜题要孩子凭直觉就会想错一次。
2. **真相表。** 收齐真实的数字和规律，每一条写出处（教材、NHGRI、MedlinePlus、Britannica 一类的机构）。写成一个小模型（一个纯函数或一个 `MODEL` 对象），页面上的读数、动画、图注都从它算出来，不在别处另写数字。拿不准的事实，查到出处才用；查不到就不用。
3. **发明实物。** 用一句话写清楚：「孩子 ___（动作），这个动作就是 ___（知识）」。选孩子在生活里见过的东西：线轴、抽屉、天平、尺子、显微镜、拼图台。不要照搬参考图，只借它的质感。
4. **零件清单。** 列出画面上的每个零件，分组写：
   - **主角**：只有一个，用唯一的强调色（陶土红）。孩子的眼睛应该一直盯着它。
   - **刻度和读数**：尺子、表盘、计数器。读数用孩子世界里的东西作对照。
   - **控件**：把手、滑块、拖动的部件。手指能抓到，至少 48 px。
   - **环境**：底座、桌面、显微镜视野的圆框。让它像一个真东西，但不抢主角。
   每个零件都要有用途，不画装饰。
5. **三拍加一个结尾。**
   - **猜**：先让孩子预测，选项里放真实的误区（每个错误选项对应一个误区 id）。
   - **动手**：孩子操作实物，读数实时变化。这一拍占大部分时间。
   - **揭晓**：一句话说清刚才看到的是什么，再给一个让人「哇」的数字。
   - **成就**：结束时孩子手里有一件自己做出来的东西，比如排好的染色体图、一张写着他的读数的星卡。不要只给一个分数。

## 「哇」时刻

每个知识点至少一个。两种来源：
- **尺度换算**：把真实的数字换到孩子的世界里。例如「如果细胞核有乒乓球那么大，里面的 DNA 拉直了大约有 13 公里，要走三个小时」。换算要用真相表算出来。
- **反直觉的事实**：例如「21 号染色体其实比 22 号还小，当年科学家排队时看走了眼」。

## 挑战要有难度，不要复述

- 题目考的是用刚才的实物去推理，不是复述刚才那句话。例如「狗有 78 条染色体，它有几对？」「这根短棒最可能和哪根配对？」
- 难度一题比一题高，最后一题要让孩子用尽全力才做得出来。
- 答对了给具体的反馈（「你看出了它们的条纹一样」），不要只说「对了」。

## Claude 画风

- **纸和墨**：浅色是暖纸面 `#F5F4EE`，墨线 `#1F1E1C`，手绘的线带一点抖动，线头是圆的。深色是 Obsidian 风格的夜色，墨线换成浅色。两种模式共用同一套线稿。
- **淡彩**：鼠尾草绿 `#CCD6C0`、天蓝 `#CFDCE6`、杏色 `#ECCDB6`、纸色 `#EFE4D6`，透明度 0.6 到 0.85，色块不描边。
- **强调色**：陶土红 `#C2603F`，整个画面只给主角用。爸爸蓝 `#4F7FA8`、妈妈红 `#C2603F` 这类有意义的颜色，要在图注里说明。
- **字**：标题用衬线体，读数用等宽数字。画面里最多几个短标签，说明放在画面外。
- **卡片**：每一站是一张卡片。左上写「第 1 站 · 共 3 站」，右上写标题，左下写操作提示（「转动把手」），右下写实时读数。
- **动效**：克制。用指数跟随或真实的弹簧，不用花哨的弹跳。没人碰时可以慢慢演示一遍。尊重 `prefers-reduced-motion`：动画变成直接到位，内容不少。
- **留白**：画面占卡片的六成左右，四周留空。

## 适龄

- **三四年级**：一屏只做一件事。字少，句子短，说具体的东西。动作要大：拖、转、按住。数字配孩子世界里的对照（身高、操场、乒乓球）。不出现「学习」二字。
- **初中以上**：可以显示单位、公式和真实数值，可以给两个控件让孩子比较。

## 落到好奇号

- **形式**：要能动手，就做成模拟或实验模块：`manifest.yaml` 加单文件 `index.html`，走 `docs/activity-contract.md` 的 activity/1.1 契约。不联网，不读写存储，不用外部 CDN。「预测 → 观察 → 解释」里的预测和解释由平台负责。讲解和挑战也可以嵌入这样的模块，不要只用文字步骤。
- **写提示词**：派发给实现 AI 时，提示词里必须有上面的 1 到 5：谜题、带出处的真相表、一句话实物、零件清单、三拍加结尾。还要写清楚「哇」时刻和成就物，以及逐屏的验收清单。只写「不许做什么」的提示词，做出来就是没错但无聊。
- **审核**：除了科学准确和文案规则，还要按下面「检查」一节看趣味和成就感。不满足的，和事实错误一样打回。

## 工具包（都在本技能的 `references/` 下）

| 文件 | 什么时候用 |
| --- | --- |
| `lessons.md` | **每次都先读。**做「生命的说明书」三个模拟模块时踩过的坑和定下的做法。写提示词时把「实现」一节原样贴进去；审查时逐条对照；发现新坑就补进去。 |
| `starter.html` | 新模块从它起步，不要从零写。卡片、领航员气泡、「我有个问题」、activity/1.1 契约、手绘线、按住按钮（含松手防误点）、缓动和完成判定 `fin()` 都写好了，只要换掉 `{{…}}` 和两个示例站。 |
| `brief-template.md` | 给实现者的设计说明（提示词）模板，以及派给子 agent 时附上的话。实现用 Opus。 |
| `review-template.md` | 给审查者的提示词模板，以及收到审查后怎么处理。审查用 Sonnet，和实现者不是同一个模型。 |
| `walk.py` | Playwright 走查脚本的样例（染色体模块）。改出每个模块自己的版本：平板、手机、电脑三种宽度，浅色深色，reduced-motion，逐站截图。 |

三个标杆模块（风格和质量以它们为准）：`content/activities/act.simulation.chromosome-pack-01/`（Claude 自己做的第一个）、`act.simulation.cell-zoom-01/`、`act.simulation.dna-book-01/`。它们的设计说明在 `prompts/` 下同名文件，审查记录在 `docs/reviews/`。

### 一个模块的完整流程

1. 用本技能拆解知识点，按 `brief-template.md` 写设计说明，存为 `prompts/act.simulation.<名字>-01.md`。
2. 派 Opus 子 agent 实现（附上模板里那段话），它从 `starter.html` 起步，自己走查、迭代、跑 `tools/ci_checks.py`，不提交。
3. 维护者在知识点卡的 `activities` 里登记新活动（实现者不改别的文件），跑 CI。
4. 派 Sonnet 子 agent 审查（`review-template.md`）。阻断和重要逐条改，改完重新走查；审查和答复存进 `docs/reviews/`。
5. 新坑补进 `lessons.md`；能放进骨架的做法同步改 `starter.html`。
6. 用 `preview/build.py` 生成试玩页给家长试，孩子试玩后再合入。

## 检查

像挑刺的人一样检查。手机（390 px 宽）、平板、电脑各截一张图，浅色和深色各一张，动起来的几个瞬间也要截。每张图都要打开看。然后回答：

1. 不看任何字，能看懂画面在演什么吗？
2. 孩子的动作真的改变了实物的状态吗？读数跟着变吗？
3. 有让人「哇」的数字或事实吗？它是从真相表算出来的吗？
4. 做完以后，孩子手里有自己做出来的东西吗？
5. 孩子会想再玩一次吗？
6. 画面上的每个数字都有出处吗？
7. 放大看，线条有没有断在半空、文字有没有挤出卡片？

有一条答「不」，就接着改。

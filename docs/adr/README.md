# 架构决策记录（ADR）

每份 ADR 记一个影响长期的架构决定：当时的背景、决定了什么、放弃了什么、会带来什么后果。

ADR 一旦接受就不改写。要推翻某个决定，就写一份新的 ADR，在里面注明「取代 ADR-00x」，旧的那份状态改为「已被取代」。这样十年后还能查到当初为什么这么做。

## 状态

- **提议**：Claude 起草，等 Luka 拍板。
- **已接受**：Luka 确认，开始照此执行。
- **已被取代**：被后来的 ADR 推翻，原文保留。

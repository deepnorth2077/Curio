# ADR-011 画风与手感只有一个出处：运行时状态由宿主下发，共用零件按版本抄进模块

- 状态：已接受（2026-11-11 起草，经 PR #108 审阅修订；2026-11-21 Luka 拍板配色与范围，2026-11-25 拍板纳入程序化微音效）
- 日期：2026-11-11（2026-11-25 修订）
- 相关：#107、#108；ADR-003（发布不可变，含增补 1）、ADR-005（活动宿主）、ADR-008（不打包）；`docs/activity-contract.md`；`docs/specs/kit.md`

## 背景

Curio 的画风（暖纸面、手绘墨线、淡彩色位、圆钮）和机关把玩手感现在分散在多处，而且已经出现不一致与体验缺口：

1. **颜色和字体变量**在 `prototype/index.html`、`app/index.html`、`preview/template.html`、`references/starter.html` 和每个模块的 `index.html` 里各有一份。两套名字并存：外壳叫 `--c-sci`、`--c-math`、`--wash`，模块叫 `--sage`、`--apricot`、`--paper`；深色模式下外壳强调色是紫色 `#A797F7`、纸色是 `#2A2738`，模块却是赭色 `#E0876A`、纸色 `#33302A`。
2. **颜色下发路径不统一。**activity/1.1 的 `init.palette` 没有规定键名：原型内置模块（`pinholeModule`、`quizModule`）收到驼峰键 `accentSoft`、`sci`；原型 `runSim` 对外部模块只发 7 个中性色键（不含 `accent` 和淡彩）；试玩页发空表；正式外壳 `app/` 尚未下发 `palette` 和明暗模式。
3. **手绘线和页面骨架**（`sketchLib`、`Host`、圆钮 `grip`、上下分数 `fracS`、站切换、防误触）在二十多个模拟模块里整段抄写，每个模块约 800 到 1300 行。多模型对比里，曾有一份交付只改错了手绘曲线函数的一个下标，整屏的线都扭了（`docs/reviews/bench.chocolate-split-01.md`）。
4. **全站完全静音，缺少把玩机关的听觉触感。**小火箭跳步、掰开巧克力、转动圆钮棘轮、点亮星星都没有听觉反馈；但如果让各模块自己引音频文件或随便写振荡器频率，既违反单文件离线约束，又会让音量和音色失控，且沙箱模块读不到 `localStorage` 里的静音设置。
5. 平台要用约十年。期间一定会调配色、修骨架缺陷（`lessons.md` 已有三十多条）、统一触感与微音效。

同时有三条已接受的约束不能破：模块是单文件、不联网、不读写存储、单独打开也能玩（契约、ADR-005）；发布不可变，同一个发布的字节永远不变（ADR-003）；浏览器运行前不要求打包，提交进仓库的文件就是能运行的文件（ADR-008）。

## 决定

把「画风与把玩手感」分成两类东西，用两种办法管：

1. **运行时的外观与开关状态由宿主下发。**指颜色表、明暗模式、领航员表情、静音开关。契约升到 `activity/1.2`：
   - `init.palette` 固定 20 个平台色位与状态键（即 CSS 变量去掉 `--`：`bg`、`pane`、`hover`、`rule`、`ink`、`text`、`muted`、`accent`、`accent-soft`、`grip`、`grip-soft`、`sage`、`sage-bg`、`sky`、`apricot`、`paper`、`good`、`good-soft`、`bad`、`bad-soft`）。领域专用色（如遗传模块的 `dad`、`mom`）留在模块自身变量里，不进平台契约。深色强调色统一采用外壳紫色 `#A797F7`，纸色 `#2A2738`。
   - `init.scheme`：`"light"` 或 `"dark"`。1.2 模块据此切换 `.kit-dark` 类与 `color-scheme`，不再自己看系统的 `prefers-color-scheme`。
   - `init.muted`：布尔值，表示当前是否静音。沙箱内不读存储，静音偏好由外壳统一保存并下发。
   - `init.navigator`：可选的领航员六张表情 SVG（并入 1.2 字段表，沿用 `docs/specs/navigators.md`）。
   - 外壳在活动运行中途切换明暗或静音时，发 `theme`（`{palette, scheme}`）或 `mute`（`{muted}`）消息，模块即时响应，无需重开活动。
2. **颜色源文件与冻结代码文件分开。**
   - `kit/tokens.css` 不分版本、可修改，只通过 `curio-tokens` 标记同步进外壳文件；宿主在运行时从外壳读取这 20 个键下发给 1.2 模块。「改一次配色全站跟着变」改的是 `kit/tokens.css`。
   - `kit/<版本号>/`（`kit.css`、`kit.js`、`README.md`）是按正整数版本管理的冻结代码：包含后备默认色、三种手绘线、`Host`、`sketchLib`、圆钮与分数零件、页面骨架，以及**程序化微音效引擎 `Sfx`**。一旦某个版本被合入 `main` 的模块使用，该目录字节永久冻结；修缺陷或加新零件出新版本目录。
3. **代码按版本抄进模块，由工具管，由 CI 逐字节核对。**
   - 模块的 `index.html` 用注释对标出库的位置（`/* curio-kit:1 begin */` … `/* curio-kit:1 end */`，样式和脚本各一段）。`tools/kit.py sync` 写入、`tools/kit.py check` 核对，只扫描明确清单里的文件（不扫文档和生成副本）。写进去后的 `index.html` 直接提交，本身即可独立运行。
   - `activity/1.2` 模块的 `manifest.yaml` 必填 `kit: <版本号>`，CI 核对契约版本与库版本对应、段落逐字节一致，且标记段外不重声明库导出的名字。
4. **程序化微音效（Web Audio API）作为一等共用零件纳入 `kit/` 与外壳。**
   - 不引入任何音频文件、不加背景音乐、不循环播放。只用原生 Web Audio API 实时合成极克制的短促物理微音效（`15ms～600ms`，峰值增益 `<= 0.12`）。
   - 统一定义 7 个语义「声位」（`Sfx.tick` 棘轮刻度、`Sfx.hop` 跳步、`Sfx.snap` 掰开咔哒、`Sfx.tap` 轻触、`Sfx.right` 答对与过站、`Sfx.nudge` 误区轻叩、`Sfx.lit` 星星点亮泛音和弦）。外壳（`app/sfx.js`）与模块（`kit/<N>/kit.js`）共用同一套声位设计与合成参数，外壳提供全局静音开关。
   - 无 `AudioContext`、未解锁手势或 `muted: true` 时静默降级为无操作，绝不抛错。
5. **色位名统一，原型冻结，分步兼容。**
   - 淡彩统一用 `sage`、`sky`、`apricot`、`paper` 作为「色位名」（不绑定学科）；外壳旧名（`--c-sci`、`--c-sci-bg`、`--c-math`、`--c-sky`、`--wash`）留作别名。
   - 原型 `prototype/` 已冻结（`docs/handoff.md`），主线只改正式外壳 `app/`、试玩壳 `preview/template.html`、骨架与模块。
   - 宿主同时认 `activity/1.1` 和 `activity/1.2`：对未迁移的 `1.1` 模块保持现有下发行为不变，画面零回归；只对 `1.2` 模块发 20 色、`scheme` 和 `muted`。宿主支持先行或同步合入，再迁标杆模块验证。

## 放弃的方案

- **宿主在运行时把脚本库注入模块。**模块单独打开就不能玩，且破坏沙箱边界与字节可复现性。
- **另设源文件，构建时才生成 `index.html`。**违反 ADR-008「提交进仓库的文件就是能运行的文件」。
- **使用 `.mp3` / `.wav` 音频资源或 Base64 音频片段，或加入背景音乐。**外部音频文件违反模块零网络请求与单文件约束；Base64 音频会让每个单文件膨胀数十至数百 KB；背景音乐喧宾夺主，不符合克制审美。Web Audio 程序化合成只需几十行代码，零体积负担且音高可随步数、刻度动态微调。
- **让每个模块自己写 `AudioContext` 振荡器代码。**音色、音量、防抖节流与静音开关会失控，必须像色位一样收进零件库统一管理。
- **把线宽、字号、动效快慢放进契约。**没有运行时动态改它们的需求（`docs/standards.md`）。

## 后果

- 改配色：只改 `kit/tokens.css` 并同步到外壳，正式外壳与所有 `1.2` 模块在运行时一起变。
- 切换明暗或静音：在外壳一键切换，外壳挑战与沙箱内的动手探索同步生效。
- 修骨架或微音效零件：出 `kit/<N+1>/`；需要更新的模块各自升版审查，已发布旧模块不被悄悄改动。
- ADR-003 增加增补 1：历史发布的「打开那一版看」保证当时的逻辑、数值、文案、版式和零件版本；运行时配色、领航员外观和静音开关随当前外壳。

## 拍板结果（Luka）

1. **2026-11-11**：契约升到 `activity/1.2`；淡彩色位名统一为 `sage`、`sky`、`apricot`、`paper`，外壳旧名留作别名；先迁移标杆模块验证，其余随改版迁移。
2. **2026-11-21**：按审阅意见缩小范围，从正式外壳 `app/` 和已接入活动共用的零件做起（冻结原型）；深色强调色统一沿用外壳紫色 `#A797F7`（纸色 `#2A2738`）。
3. **2026-11-25**：将极克制的 Web Audio 程序化微音效（无背景音乐，含棘轮、跳步、掰开咔哒、点亮泛音和弦等语义声位及全局静音开关）一并零件化，纳入 #107 / #108。

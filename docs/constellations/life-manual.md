# 星座说明：生命的说明书

这份文件是「生命的说明书」星座里全部活动的共同约定。每个活动的任务文件都会原样嵌入下面几节，所以几个实现 AI 分头写，讲出来的话、用的词、画的图还是一套。

## 星座概况

- **舰长**：小学三年级的孩子，8 岁左右。最近对「染色体」特别好奇，家长希望从零开始，像私人导师一样带他弄明白。
- **三颗星，按顺序**：细胞 → DNA → 染色体。前一颗星讲到的东西，后一颗星可以直接用；后一颗星的东西，前一颗星不提前讲。
- **每颗星的活动**：一份讲解（领航员对话，约 5 分钟）、一份挑战（约 5 分钟）；染色体另有一份反思。
- **讲解和挑战由不同的人分头写**，彼此看不到对方的稿子。所以挑战里只能用下面「词表」里本颗星和前几颗星的词，讲解必须把本颗星的新词都讲到。

| 星 | 知识点 id | 讲解 | 挑战 | 反思 |
| --- | --- | --- | --- | --- |
| 细胞 | `biology.cell.cell-intro` | `act.explain.cell-intro-01` | `act.quiz.cell-intro-01` | — |
| DNA | `biology.genetics.dna-intro` | `act.explain.dna-intro-01` | `act.quiz.dna-intro-01` | — |
| 染色体 | `biology.genetics.chromosome-intro` | `act.explain.chromosome-intro-01` | `act.quiz.chromosome-intro-01` | `act.reflection.chromosome-intro-01` |

## 领航员怎么说话

讲解用领航员对话（`style: tutor`）。领航员是飞船上陪舰长探索的向导。

- **称呼**：叫孩子「舰长」，自称「我」。不说「同学们」「小朋友」「老师」，不出现「学习」二字。
- **一步一两句**：每个 `text` 步骤只说一两句话，一般不超过 40 个字，最长不超过 60 个字。一次只讲一件事。
- **先问再讲**：每颗星都从驱动问题开场，先让舰长想一想，再给答案。每讲两三件事，停下来用一个 `check` 小问题确认，全篇至少 2 个 `check`。
- **像一起探险**：语气好奇、平等，说具体的东西（积木、毛线、说明书、小线轴），少用抽象的词。不堆感叹号，一篇里感叹号不超过 3 个。
- **答错时先接住**：错误选项的 `feedback` 先承认这个想法有道理（「很多人都这么想」「看起来确实像」），再用一句话说清哪里不对。不说「错了」「不对哦」开头。
- **结尾留钩子**：最后一步留一个让人想往下点的问题，指向下一颗星（染色体是最后一颗，就请舰长去写反思，或者把还想知道的事告诉领航员）。
- **比方要一路用下去**：细胞是「小房间」，细胞核是放说明书的「小房间里的小房间」，DNA 是「说明书」，染色体是「卷好收起来的说明书」，基因是「说明书里的一段」。三颗星都用这一套比方，不换新的。

## 配图风格

讲解需要的图，用 SVG 画，存为 `content/assets/<知识点 id>/<文件名>.svg`，在步骤里写成 `{type: svg, src: content/assets/…}`。

- **样子**：手绘感，像在暖色纸上用墨线勾、再刷一层淡彩。线条略带一点抖动（用 `path`，不要全是完美的圆和直线），线头是圆的。
- **墨线**：`fill="none" stroke="#1F1E1C" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"`，同时加 `class="k"`（细一点的线用 `stroke-width="1.3"` 和 `class="k1"`）。平台显示深色模式时会通过这两个 class 把线条换成浅色，所以 class 一定要写。
- **淡彩**：只用这几种颜色做色块，`fill-opacity` 在 0.6～0.85 之间，色块不描边（描边由墨线负责）：
  - 鼠尾草绿 `#CCD6C0`（生命主题的底色）、天蓝 `#CFDCE6`、杏色 `#ECCDB6`、纸色 `#EFE4D6`
  - 要区分「来自爸爸」和「来自妈妈」时，爸爸用蓝 `#4F7FA8`、妈妈用陶土红 `#C2603F`，全星座统一，并且在图注里说明哪种颜色是谁。
- **不要**：背景色块（画布透明）、阴影、渐变以外的特效、照片、写实的人体器官。图上的字越少越好，最多几个短标签（`font-size` 不小于 14），说明放在 `caption` 里。
- **大小**：写 `viewBox`（例如 `0 0 480 300`），不写死 `width`、`height`。
- **白名单**：只用内容规格 3.6 列出的元素和属性；不用 `<style>` 和 `style` 属性。
- **画染色体**：画成两头圆的短棒，**不要画成 X 形**（X 形是细胞准备分裂时的样子，而且会和「X 染色体」搞混）。X、Y 染色体画成一长一短两根短棒，用字母标出来。

## 事实和出处

下面的事实已经核对过，可以直接用，写进活动的 `sources`。要用这里没有的事实，必须自己找到可靠出处（教材、课标、NHGRI 这类机构网站）写进 `sources`；找不到出处就不用。

| 事实 | 出处 |
| --- | --- |
| 人、动物和植物都是由细胞组成的；细胞很小，大多数要用显微镜才能看见 | 人教版初中生物学七年级上册（2024 年版）第一单元第二章「认识细胞」 |
| 动物和植物的细胞一般都有细胞核；人成熟的红细胞没有细胞核 | 同上；人教版初中生物学（2024 年版）第四单元「人体生理与健康」讲血液的一节 |
| 细胞能分裂，一个变成两个 | 人教版初中生物学七年级上册（2024 年版）第一单元第三章第一节「细胞通过分裂产生新细胞」 |
| DNA 在细胞核里，是主要的遗传物质 | 人教版初中生物学八年级下册（2024 年版）第六单元第二章第二节「基因在亲子代间的传递」 |
| 染色体由 DNA 和蛋白质组成；DNA 缠在像线轴一样的蛋白质上 | 同上；NHGRI「Chromosome」词条 https://www.genome.gov/genetics-glossary/Chromosome |
| 一个人体细胞里的 DNA 全部拉直，大约有 2 米长（约 6 英尺） | NHGRI 染色体知识页 https://www.genome.gov/about-genomics/fact-sheets/Chromosomes-Fact-Sheet |
| 人的体细胞一般有 46 条染色体，配成 23 对；每对一条来自父亲、一条来自母亲 | 人教版八年级下册（2024 年版）第六单元第二章第二节 |
| 第 23 对是性染色体：女性一般 XX，男性一般 XY；男孩的 X 来自母亲、Y 来自父亲 | 人教版八年级下册（2024 年版）第六单元第二章第四节「人的性别决定」 |
| 狗有 39 对（78 条）染色体，果蝇 4 对（8 条），水稻 12 对（24 条） | NHGRI「Chromosome」词条 |

**容易讲错的地方**：

- 不要说「每个细胞都有细胞核」「每个细胞都有 DNA」，要说「一般」「绝大多数」，红细胞是例外。
- 不要用「头发里有 DNA」举例：头发露在外面的部分是已经死掉的细胞，几乎没有细胞核。举例用皮肤、口腔里的细胞、肌肉。
- 不要说「染色体就是 DNA」：染色体是 DNA 缠在蛋白质上再折叠起来的。
- 不要说「孩子的长相一半像爸爸一半像妈妈」：是**说明书**一半来自爸爸、一半来自妈妈；长得更像谁，每个人不一样。
- 说性别时用「一般」：女孩一般是 XX，男孩一般是 XY。
- 染色体数目和个子大小、聪不聪明都没有关系：狗 78 条，比人还多。

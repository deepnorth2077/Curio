# 物理与化学

## 物理

同一星座可以从小学进入，也可以从初中或高中进入。表中的任务举例说明一个知识簇要教到什么程度。高中必修、选择性必修的位置依据 2017 年版 2025 年修订课标。小学部分取自科学课中的物质、运动、能量和工程主题。学段之间采用知识递进顺序，各地教材可以有不同册次。[义务教育科学课标修订组解读](https://xuanshu.hep.com.cn/front/h5Mobile/bookDetails?bookId=697a4252e119ac972922bdfd) · [义务教育物理课标日常修订版](https://fxzx.qpedu.cn/jhzx/kcjs/kcbz/511641.htm) · [普通高中物理课标日常修订版](https://pmc.scnu.edu.cn/a/20251127/25.html)

| 星座 | 从哪个问题走到哪里 | 怎样验收覆盖 |
| --- | --- | --- |
| 物 01 运动的尺和钟 | 小学的位置、方向、距离和用时 → 初中的参照物、速度、长度与时间的测量 → 高中必修 1 的质点、位移、瞬时速度、加速度、匀变速直线运动与自由落体 | 给同一次往返的路线、计时和位置图，分别求路程与位移，从图像判断何时加速或折返，并说明读数的精度 |
| 物 02 力怎样改变运动 | 小学的推、拉、变形和摩擦 → 初中的重力、弹力、摩擦、惯性、平衡与相互作用 → 高中必修 1 的胡克定律、力的合成分解、牛顿运动定律、超重与失重 | 用两张受力图分清一对平衡力和一对相互作用力，根据小车的力、质量和加速度数据检验预测 |
| 物 03 沉浮与压强 | 小学的浮沉 → 初中的质量、体积、密度，固体和液体压强、大气压、流速与压强、浮力和阿基米德原理 → 高中与流体模型、气体状态联系 | 从质量和排水体积判断船能否浮起，另用受力面积解释为什么同一人穿雪板后下陷较少 |
| 物 04 省力的机器和能量账本 | 小学的杠杆、轮轴、滑轮、斜面 → 初中的力臂、功、功率、机械效率、动能与势能 → 高中必修 2 的功、动能定理、势能和机械能守恒条件 | 比较两种提升同一货物的方案，区分省力、省功、省时，判断含摩擦的路线中机械能和总能量各怎样变化 |
| 物 05 从落苹果到绕地飞行 | 小学对太阳、地球和月球运动的观察 → 初中的运动相对性与尺度 → 高中必修 2 的运动合成分解、平抛、圆周运动、开普勒定律、万有引力、轨道与相对论初步 | 用同一运动图分别标出切向速度和向心加速度，解释卫星持续下落却能绕地飞行，辨认经典时空模型的适用尺度 |
| 物 06 碰撞的一瞬间 | 初中对碰撞前后运动的观察 → 高中选择性必修 1 的冲量、动量定理、动量守恒、碰撞与反冲 | 根据两辆小车碰前碰后的速度和质量，分别检验系统的动量与动能，说明选择哪段时间、哪个系统 |
| 物 07 振动怎样走远 | 小学发声、响度和音高 → 初中声的传播与利用、噪声控制 → 高中选择性必修 1 的振动与波、简谐运动、单摆、共振、波速、干涉、衍射与多普勒效应 | 对照一个点的振动图和整条绳某一时刻的波形图，判断周期、波长和传播方向，解释行驶车辆的声音为何变调 |
| 物 08 看见与成像 | 小学的光源、影子、镜子 → 初中的传播、反射、折射、色散、透镜、眼睛和成像 → 高中选择性必修 1 的折射率、全反射、干涉、衍射、偏振与应用 | 在相机中追踪两条光线判断像的位置，再用条纹证据说明仅靠几何光线难以解释的现象 |
| 物 09 冷热背后的粒子 | 小学的冷热、热传递、物态变化 → 初中的六种物态变化、分子运动、内能与热量、比热容、热机 → 高中选择性必修 3 的分子动理论、固液气性质、气体状态变化和热力学定律 | 读温度随时间变化的图，与粒子模型对应，区分吸热、升温与做功，用给定压强和体积数据检验气体模型 |
| 物 10 看不见的电场 | 生活中的静电 → 初中的电荷、导体与绝缘体 → 高中必修 3 的库仑力、电场、电势、电势能、电势差、电容和带电粒子的运动 | 对照电场线、等势线和粒子电性，判断受力、做功、电势能变化，解释电容器充放电曲线 |
| 物 11 电路里的收支 | 小学的小灯和回路 → 初中的串并联、电流、电压、电阻、欧姆定律、电功率、焦耳定律与安全用电 → 高中必修 3 的电阻率、电动势、内阻与闭合电路 | 给电路图、仪表量程和伏安数据，解释两灯亮度及电源端电压的变化，用电能与时间核对功率 |
| 物 12 磁场中的力 | 小学的磁铁和指南针 → 初中的磁场、电流的磁效应、电磁铁和电动机 → 高中必修 3 的磁场概念与选择性必修 2 的安培力、洛伦兹力 | 对照指针示意图、载流线圈及带电粒子轨迹，辨别磁场作用的对象及力的方向 |
| 物 13 把机械能变成电能 | 初中的发电机与能量转化 → 高中必修 3 的电磁感应初步 → 选择性必修 2 的磁通量、楞次定律、感应电动势、自感、电磁阻尼、交变电流、变压器和输电 | 根据线圈磁通量的变化图判断感应方向，比较同一输送功率下两种输电方案的线路损耗 |
| 物 14 电磁波和传感器 | 小学用感官或仪器接收信号 → 初中的电磁波、信息传递与通信 → 高中必修 3 的电磁波谱 → 选择性必修 2 的电磁振荡、发射接收与传感器 | 用频率、波长辨认波段，读传感器标定曲线，说明一个自动照明系统如何把光信号变为控制信号 |
| 物 15 光子与原子 | 初中的微观尺度 → 高中选择性必修 3 的原子结构、能级、光谱、光电效应、光子与波粒二象性 | 根据线光谱辨认能级差，从光电效应数据区分频率和强度各改变什么；电子排布与元素性质链接「元素的家谱」 |
| 物 16 原子核里的变化 | 初中的原子核与核能概念 → 高中选择性必修 3 的核组成、核素、天然放射性、衰变、半衰期、结合能、裂变与聚变 | 读衰变曲线判断多个半衰期后的剩余比例，从质量与能量的数据解释太阳为何能持续发光 |
| 物 17 能源选择与技术取舍 | 小学的能源、材料和工程设计 → 初中的能源分类、能量守恒与转移、物理与社会 → 高中必修 3 的能源与可持续发展 | 给定一座校园的用电时段、能源供应、效率和环境数据，比较两个方案，指出还缺哪条证据才能决定 |

### 课程覆盖

 初中五个主题中，「物质」落在物 03、09、15、16，「运动和相互作用」落在物 01–03、05、07–08、10–14，「能量」落在物 04、09、11、13、16–17。「实验探究」贯穿测量读数、变量控制、图像解释、模型验证和误差分析，如物 01、02、03、06、07、08、11、13、14。「跨学科实践」可在物 04、08、14、17 验收设计、数据与方案取舍。高中必修 1 对应物 01–02，必修 2 对应物 04–05，必修 3 对应物 10–14、17。选择性必修 1 对应物 06–08，选择性必修 2 对应物 12–14，选择性必修 3 对应物 09、15–16。自主选修「物理学与社会发展」「物理学与技术应用」挂入物 04、08、11–14、17，「近代物理学初步」挂入物 05、15–16，可延伸至高速、宇观与量子世界。天体如何运动归物 05，辨认星空和天体系统的目录与地球宇宙领域相连。[初中物理课标修订组解读](https://xuanshu.hep.com.cn/front/h5Mobile/bookDetails?bookId=697a4254e119ac972922bf54) · [高中各科日常修订版全文入口](https://www.scmlzx.net/news/202511/497838942620618752.html)

## 化学

小学的材料、空气、水、溶解和物质变化从科学课进入。初中建立物质类别、组成与变化的基础，高中必修推进到物质的量、结构、反应和应用。高中选择性必修分别深化反应原理、物质结构与性质、有机化学基础。[义务教育化学课标日常修订版](https://fxzx.qpedu.cn/jhzx/kcjs/kcbz/511628.htm) · [高中化学课标修订组解读](https://xuanshu.hep.com.cn/front/book/findBookDetails?bookId=6a6a3491e119ac97299a8f50)

| 星座 | 从哪个问题走到哪里 | 怎样验收覆盖 |
| --- | --- | --- |
| 化 01 物质的身份证 | 小学比较材料的性质、混合与分离 → 初中的纯净物与混合物、单质与化合物、物理与化学性质 → 高中必修的分类及分散系、胶体 | 给水、盐水、泥水和胶体的观察记录，提出有依据的分类，并说明分离依据的性质 |
| 化 02 空气和水 | 小学认识空气占据空间、水的状态变化 → 初中的空气组成、氧气与二氧化碳、水的组成和净化、自然界的水 → 高中以常见物质认识资源利用 | 解释为何海水淡化后仍是水，水发生化学分解后却出现不同物质；用组成数据和颗粒图提供依据 |
| 化 03 元素的家谱 | 初中的分子、原子、离子、元素符号与周期表 → 高中必修的核素、核外电子排布与元素周期律 → 选择性必修 2 的电子云、轨道、能级、基态排布和性质递变 | 给定一组原子或离子的信息，判断哪些属于同一元素，从排布解释同族相似性，比较周期趋势 |
| 化 04 粒子怎样牵手 | 初中从粒子认识物质构成 → 高中必修的离子键与共价键 → 选择性必修 2 的化学键、分子空间构型与极性、分子间作用力、氢键、晶体结构及配位作用 | 比较食盐、金刚石、冰、铜，用粒子种类和相互作用解释熔点、导电性等差异，辨别分子内和分子间作用 |
| 化 05 怎样数一杯水里的粒子 | 初中的化合价、化学式、相对质量、组成和方程式计算 → 高中必修的摩尔、摩尔质量、粒子数、规定条件下的气体摩尔体积与物质的量浓度 | 从同一样品的质量推得物质的量与粒子数，再核对反应方程式中的比例，指明换成体积时需要哪些条件 |
| 化 06 变化前后什么守恒 | 小学区分形态变化与新物质产生 → 初中的典型反应、质量守恒、化学方程式、燃烧与灭火 → 高中必修的离子反应、电子转移和氧化还原 | 从宏观记录、粒子图和方程式三种表示说明哪些物质改变，逐项核对元素、原子数、电荷与电子得失 |
| 化 07 溶液里的粒子 | 小学的溶解与影响因素 → 初中的溶液、饱和、溶解度、质量分数、酸碱盐、pH与中和 → 高中必修的电解质与离子 → 选择性必修 1 的电离、水的电离、盐的水解、酸碱平衡、沉淀溶解平衡 | 分别读溶解度图、酸碱滴定数据和离子浓度资料，解释溶质多少、溶液酸碱性、沉淀能否存在三个不同问题 |
| 化 08 非金属的循环 | 空气与岩石中的非金属元素 → 初中的碳、氧及常见化合物 → 高中必修的氯、硫、氮、硅及其代表物质，元素类别、价态与转化 | 选一种元素，在给定转化图中追踪其去向、价态和物质类别，解释同一种元素为何能出现在性质迥异的物质中 |
| 化 09 金属从哪里来 | 小学的金属性质和材料选择 → 初中的活动性、合金、金属资源、腐蚀与回收 → 高中必修的钠、铁等代表物质与冶炼，进一步联系电化学腐蚀与防护 | 给几种材料的活动性、耐蚀性、质量与回收数据，为同一物件选择材料，解释表面发生的化学变化 |
| 化 10 化学能怎样变成电能 | 小学电池用作电源 → 高中必修的化学能、热能与电能转化 → 选择性必修 1 的反应热、焓变、盖斯定律、原电池、电解池、电极过程和能量效率 | 用热化学数据核对同一反应不同路径的焓变，再根据电池示意图追踪电子和离子，判断能量转化方向 |
| 化 11 反应能走多快多远 | 由生活中的快慢变化进入 → 高中必修的反应速率与限度、可逆反应 → 选择性必修 1 的速率影响因素、催化、平衡常数、平衡移动和过程方向 | 给两组随时间变化的浓度曲线，分别判断达到平衡的时间与平衡组成，辨认催化作用与平衡移动 |
| 化 12 碳骨架的许多可能 | 初中的常见有机物 → 高中必修的烃、乙醇、乙酸等代表物质 → 选择性必修 3 的命名与结构测定、同分异构、官能团、烃及衍生物、反应类型和合成思路 | 比较同分子式的结构，从性质资料或谱图辨认官能团，检验给定转化图中碳骨架与官能团变化是否相符 |
| 化 13 从小分子到大分子 | 小学的食物和材料 → 初中的营养物质与合成材料 → 高中必修的糖类、油脂、蛋白质 → 选择性必修 3 的生物大分子、单体、聚合物、加聚、缩聚与结构性能 | 根据材料结构判断小分子、天然高分子或合成高分子，关联重复单元、结构和材料用途；营养与生命功能链接生命科学 |
| 化 14 物质使用后的去向 | 小学材料再用、生活垃圾 → 初中的资源、环境、燃料、化肥和生活化学 → 高中必修的资源开发、材料、环境治理与绿色化学 | 比较两份产品全生命周期记录，追踪某一元素从原料到废物的去向，结合资源消耗、回收和排放解释方案取舍 |
| 化 15 证据怎样支持结论 | 小学区分观察与推测、设置对照 → 初中的实验室安全、测量、对照、鉴别、分离与证据推理 → 高中的定量分析、模型与实验方案评价、现代仪器证据 | 从一份含空白对照、异常值与重复测量的实验记录中找出支持结论的数据，说明还有哪一种解释未被排除 |

### 课程覆盖

 初中「科学探究与化学实验」以化 15 为主，借化 01、02、06、07、09 的现象和数据验收。「物质的性质与应用」对应化 01–02、07–09、13，「物质的组成与结构」对应化 03–05，「物质的化学变化」对应化 06–11，「化学与社会·跨学科实践」对应化 02、09、13–15。高中必修的科学与实验主题对应化 01、05、15，无机物主题对应化 02、06–09，结构基础与反应规律对应化 03–07、10–11，简单有机物主题对应化 12–13，化学与社会发展对应化 09、13–15。选择性必修「化学反应原理」对应化 07、09–11，「物质结构与性质」对应化 03–04、15，「有机化学基础」对应化 12–13、15。自主选修「实验化学」挂入化 15 及各物质星座，「化学与社会」挂入化 09、13–14，「发展中的化学科学」依案例挂入化 03–04、10–15。以上实验任务验收证据解释与探究设计，校内必做实验的动手考查还应对照学校实验教学目录。[初中化学课标修订组解读](https://xuanshu.hep.com.cn/front/h5Mobile/bookDetails?bookId=697a4255e119ac972922c00f) · [高中各科日常修订版全文入口](https://www.scmlzx.net/news/202511/497838942620618752.html) · [教育部中小学实验教学基本目录](https://jyt.hunan.gov.cn/sjyt/jyzbc/zbczcwj/syjx/202506/t20250605_33692362.html)

### 共用概念怎样分工

 粒子的运动与内能在物 09，元素排布与成键在化 03–04。电功、电路与功率在物 11，电池的物质转化在化 10。能源供应方案在物 17，原料到废物的化学转化在化 14。给同一对象建一份跨科链接即可。

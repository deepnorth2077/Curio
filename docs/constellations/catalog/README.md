# 小学到高中的星座总目录

Curio 第一版按 **79 个星座**规划中国小学一年级至普通高中三年级的数学与科学内容。星座由一组可以持续追问的问题组成。学段标在星座里的知识点上，同一个星座可以陪舰长走过几个学段。

| 领域 | 星座数 | 在这里能追问什么 |
| --- | ---: | --- |
| [数学](math.md) | 18 | 数怎样表示、量怎样关联、图形怎样变化、怎样从数据作判断 |
| [物理](physics-chemistry.md#物理) | 17 | 运动、相互作用、能量、波、场以及微观世界怎样解释眼前的现象 |
| [化学](physics-chemistry.md#化学) | 15 | 怎样从样品、结构与变化判断物质，怎样看待材料的用途和代价 |
| [生命科学](life-earth-engineering.md#生命科学) | 18 | 从细胞到生物圈，生命怎样运转、延续和演化 |
| [地球与宇宙](life-earth-engineering.md#地球与宇宙) | 6 | 怎样读懂天空、天气、岩石和水留下的线索 |
| [工程与科学探究](life-earth-engineering.md#工程与科学探究) | 5 | 从一个需要或问题出发，怎样设计、取证、比较与改进 |
| **合计** | **79** | 各分册按小学、初中、高中列出每个星座收哪些知识，再往下拆成单颗知识星 |

## 从知识点推到总数

先清点各学段要理解的概念和要会做的事，再合并跨年级反复出现的问题。例如，分一块饼、在数线上定位小数、按比例分果汁，操作不同，都需要判断「哪一份算作 1」。它们能共享一个星座。用天平解方程需要保持等量关系，单列一座。**只有学习目标不同、可以分别判断舰长掌握了什么，才拆成两颗知识星。**

小学科学常从同一件实物进入几门学科。下面是用义教科学的 13 项核心概念反查归属的结果。分册还列出初中分科与高中模块的去处，便于从课程要求反查星座。[课程教材研究所组织编写的科学课标修订版解读，第六至九章](https://xuanshu.hep.com.cn/front/h5Mobile/bookDetails?bookId=697a4252e119ac972922bdfd)

| 从哪类问题反查 | 主要落点 |
| --- | --- |
| ①物质的结构与性质、②物质变化与化学反应 | 化学收组成、性质和反应；物理收温度、物态与热 |
| ③物质的运动与相互作用、④能量转化与守恒 | 物理收运动、力、波、场、热和能量；从化学反应解释电池时连接化学 |
| ⑤生命系统的层次、⑥稳态与调节、⑦生物与环境、⑧生命的延续与进化 | 生命科学分别展开细胞与生物体、调节、生态、遗传与演化 |
| ⑨宇宙中的地球、⑩地球系统、⑪人类活动与环境 | 地球与宇宙收天体观测和地球过程；生物多样性保护连到生态 |
| ⑫技术、工程与社会、⑬工程设计与物化 | 工程收需求、约束、方案、测试和改进，项目用到的物理或数学知识连回原星 |

## 现在的内容放在哪里

| 已有星座 | 总目录里的位置 | 以后怎样长 |
| --- | --- | --- |
| [0 和 1 之间](../zero-to-one/index.md) | 数学，现有六组 19 颗都属于这一座 | 分数、小数、比和百分数仍可互相连线。新增「用双数轴比较两个比」（示例），只在比这一组加星。 |
| [乘法的秘密](../multiplication.md) | 数学，已有分配律知识点 | 从成组计数、拆一块长方形，走到代数式的展开与因式分解。分数乘法需要判断单位整体，可链接「0 和 1 之间」。 |
| [生命的说明书](../life-manual.md) | 生命科学，保留细胞、DNA、染色体三颗星和原来的顺序 | 以后追问性状遗传时，接到另一座的遗传推断。已玩过的染色体配对在原位。 |

以舰长提到的「数与运算」为例，小学一二年级沿「数线往哪儿走」数数、相加、求差，再到「乘法的秘密」用阵列理解几组几。三四年级进入「0 和 1 之间」，从一份有多大走到小数；五六年级仍在同一座里探索比和百分数。初中再回数线看负数、无理数，高中把数的表示扩展到复平面。新知识有自己的入口，原图上的路标仍认得出来。

这三座共 23 颗知识星。「0 和 1 之间」的 19 颗和「乘法的秘密」的掰巧克力都可以试玩，「生命的说明书」的 3 颗来自已发布的内容包。制作进度、发布状态和舰长自己的探索记录分别维护。

## 星图如何使用这份目录

从「数与运算」飞进去，选「乘法的秘密」可以掰巧克力，选「0 和 1 之间」可以按六组找齐 19 颗星。从三四年级的「生命」飞进去，第一组「生命的说明书」按顺序排着细胞、DNA、染色体；往下是「植物的生长」和「动物」。[打开星图](https://deepnorth2077.github.io/Curio/?shapes=1)

知识地铁按知识点卡上的学科主题和年级设站。23 颗星分布在数与运算线（15 站）、数量关系线（3 站）、统计与概率线（2 站）和生命线（3 站）。例如「比：味道一样的秘密」在星图里属于「0 和 1 之间」的第五组，在地铁里是六年级数量关系线的一站，两处打开同一颗星的调饮料台。[打开知识地铁](https://deepnorth2077.github.io/Curio/?shapes=1#metro)

下表给每座选一个默认入口。表内号码只用于在分册中查找。同一星座也可以从别处连过来，合计只算一次。

| 星图已有入口 | 分册中的主归属 | 座数 |
| --- | --- | ---: |
| 数与运算 | 数学 1–3，数系、运算和相对量 | 3 |
| 数量关系 | 数学 4–9、18，方程、推理、函数、变化和建模 | 7 |
| 图形与测量 | 数学 10–14，度量、作图、变换、立体和坐标 | 5 |
| 统计与概率 | 数学 15–17，计数、随机现象和数据 | 3 |
| 物质 | 化学 01–15，另加 T01 需求与设计评价（从日常材料与工具进入） | 16 |
| 能量与运动 | 物理 01–17，另加 T02 承载结构、T03 反馈控制 | 19 |
| 生命 | 生命 L01–L18，另加 T04 证据与论证（从观察生命现象进入，各科可引用） | 19 |
| 地球与宇宙 | 地球 E01–E06，另加 T05 野外调查与长期观测 | 7 |
| **合计** | **八个已有入口** | **79** |

同一个问题在多个场景出现，用一颗星作主归属，其他主题设置关联。例如「计算比例尺」归数学，「读地形图解释河流走向」归地球与宇宙，「怎样布置调查点让地图有代表性」归工程与探究。若小学从实物认识一个概念、高中用符号再次表示，可以给原星增加学段视角；若新目标需要独立推理，例如从速度读数走到瞬时变化率，就设另一颗星并连上前置知识。

79 是这一轮课程盘点得到的**内容规划数**。新活动、教材换册、知识星变多都沿用目录。遇到现有星座确实无法承载的一整串新问题，再修订目录并记录理由。星座名称目前是编辑用名；这里不分配永久内容 ID。

## 课程范围与依据

范围包括义务教育数学、科学、物理、化学、生物学和普通高中数学、物理、化学、生物学。高中同时照顾必修与选择性必修，选修中的方向标作拓展。地球与工程在高中列出自然地理、通用技术等衔接处。各分册列到可拆星的知识簇；单颗星的教材册次、课标条目和活动验收，随内容制作逐项落实。

- 义务教育以 2022 年版课程方案及分科课标为底本，结合 2025 年日常修订。数学分册的课程要求与教材章节可分别映射。[教育部原通知与各科附件](https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html) · [义务教育课程方案日常修订版](https://fxzx.qpedu.cn/jhzx/kcjs/kcbz/511668.htm)
- 高中以 2017 年版课程方案的必修、选择性必修、选修结构为基础，按 2025 年日常修订版对照内容。分册里的星座数量和名称是 Curio 的编排决定。[教育部 2020 年修订通知](https://www.moe.gov.cn/srcsite/A26/s8001/202006/t20200603_462199.html) · [高中课程方案日常修订版](https://www.scmlzx.net/uploadfile/2025/1110/%EF%BC%881%EF%BC%89%E6%99%AE%E9%80%9A%E9%AB%98%E4%B8%AD%E8%AF%BE%E7%A8%8B%E6%96%B9%E6%A1%88%E6%97%A5%E5%B8%B8%E4%BF%AE%E8%AE%A2%E7%89%88%EF%BC%882017%E5%B9%B4%E7%89%882025%E5%B9%B4%E4%BF%AE%E8%AE%A2%EF%BC%89%EF%BC%89.pdf)

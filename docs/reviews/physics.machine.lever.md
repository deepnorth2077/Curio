# 杠杆改版独立审查 · #195

审查者为 Codex 子会话 `design_jury`。新任务由主会话撰写，评审者未编写活动、挑战或验收脚本。比较基准为旧版杠杆和「切分机」实际动手画面。切分机转至七等份时，盘面抽出一角，台下留下一片样本；旧杠杆移到平衡孔，台架显示算式，最后两张凭条只写等式。

## 第一道 · 派发实现前

首稿暂缓，审读的设计稿 SHA-256 前十二位为 `7ee2c98c594a`。独立按孔距复算，一牛距支点六格与六牛距支点一格相平，一牛到第七格才会将重箱一侧抬起。移支点时两挂钩钉在木杆原孔，左四格对右两格时，用三牛可以托平右侧六牛。末题两挂点相隔五格，两边等量的组合只有「木尖距左四格，左挂一牛」。图示应表达轻杆水平释放后的起转方向，支点受力和材料变形不在此模型中。[模型依据 · OpenStax《College Physics》9.5](https://github.com/openstax/osbooks-college-physics-bundle/blob/66fcef29596e3a32818162b837dd0c85b754cbad/modules/m42174/index.cnxml)

首审要求修订的三处如下。

1. 写定第二、三、五题的干扰选项、错误反馈及第一条提示，分清「同重就平」「只看挂得远」等不同线索。预测时「最多停平」也要能回到一个具体想法。
2. 第二站的中档开场恰好已平。两枚平衡印都要经过孩子的手，初始画面不能自己取得第一枚。
3. 重箱悬挂，粉笔印须画在固定参照上。窄屏上短臂升起的缝要有足够清楚的几何差别。两排方印从同一起点逐枚对齐，让第七枚能从第六枚旁边探出去。

**复审通过，可派实现。** 修订稿 `bd65f4f51fa8` 把第六与第七孔画为可来回实测的两个瞬间，移动的是箱底相对固定印记的位置。初次平衡只开放翻纸，孩子决定何时看算式。第二站必须自己改变台架再回平，两档各盖一枚印。成品保留两次自选挂法，第三、五题的错误摆法现在均有具体读数、诊断与提示。家庭试玩会关注舰长是否主动把环推回第六孔再试，以及他是否能用手指解释自己选的两幅杆图。

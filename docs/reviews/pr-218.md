## 第一道 · 派发实现前

首稿暂缓，审读的设计稿 SHA-256 前十二位为 `7ee2c98c594a`。独立按孔距复算，一牛距支点六格与六牛距支点一格相平，一牛到第七格才会将重箱一侧抬起。移支点时两挂钩钉在木杆原孔，左四格对右两格时，用三牛可以托平右侧六牛。末题两挂点相隔五格，两边等量的组合只有「木尖距左四格，左挂一牛」。图示应表达轻杆水平释放后的起转方向，支点受力和材料变形不在此模型中。[模型依据 · OpenStax《College Physics》9.5](https://github.com/openstax/osbooks-college-physics-bundle/blob/66fcef29596e3a32818162b837dd0c85b754cbad/modules/m42174/index.cnxml)

首审要求修订的三处如下。

1. 写定第二、三、五题的干扰选项、错误反馈及第一条提示，分清「同重就平」「只看挂得远」等不同线索。预测时「最多停平」也要能回到一个具体想法。
2. 第二站的中档开场恰好已平。两枚平衡印都要经过孩子的手，初始画面不能自己取得第一枚。
3. 重箱悬挂，粉笔印须画在固定参照上。窄屏上短臂升起的缝要有足够清楚的几何差别。两排方印从同一起点逐枚对齐，让第七枚能从第六枚旁边探出去。

**复审通过，可派实现。** 修订稿 `bd65f4f51fa8` 把第六与第七孔画为可来回实测的两个瞬间，移动的是箱底相对固定印记的位置。初次平衡只开放翻纸，孩子决定何时看算式。第二站必须自己改变台架再回平，两档各盖一枚印。成品保留两次自选挂法，第三、五题的错误摆法现在均有具体读数、诊断与提示。家庭试玩会关注舰长是否主动把环推回第六孔再试，以及他是否能用手指解释自己选的两幅杆图。

设计复审后，挑战作者发现前三题的答案原先全在右端。第三题经设计者同意作镜像，五题实测答案为「右、右、左、4 格、第 4 孔配 1 牛」。第三题观测的矛盾仍是远座上的两牛敌不过近处的五牛。[本星设计与用例](../../prompts/act.simulation.lever-dock-01.md)

## 第二道 · 用孩子的入口重玩

**成品复审通过，可交杠杆一星家庭试玩。** 在最后一轮核查的活动文件 SHA-256 为 `70af908d5e29…`，挑战为 `127f7b1856b9…`。

从 `preview/build.py` 生成的课程页打开首颗星，在实际隔离的 iframe 中操作。审查覆盖手机 390 × 844 深色、平板 820 × 1180 浅色和电脑 1280 × 900 浅色并减少动效。以下是审查中打回修改的体验问题。

- **货箱与支架。** 初稿右端挂钩距离支点 45 个绘图单位，箱宽 61，支架底部向右伸 25，两幅轮廓有部分相叠。修订版调整等距孔的间隔并收窄箱侧和支架，纸板与底座之间可以看见背景。缩小后的拓杆沿用同一套轮廓。
- **掠过第六孔。** 初稿用鼠标从第一孔一气拖到第七孔，可以立刻翻看算式并收卡，孩子可能根本没看清横杆停平。修订后在手机上连续拖到第七孔、松手，此时只看到抬起的箱子。手指再点回第六孔，才能翻纸或拓杆。鼠标倒着试到六孔的复测也通过。
- **跷跷板对照。** 初稿小图仍画箱子和铁环，像同一台机器的缩印。修订后能辨认远座上的小人、近座上的大人、座板与扶手。小人那头压低，大人那头抬起。[遮字看第六孔与第七孔](physics.machine.lever/chalk-comparison.webp)

**挑战。** 在手机尺寸的试玩页故意选错再改对，把五题的所有干扰项都点过。两个不同误区「一样重必停平」和「更远的那端一定先低」分别收到挂孔与方印的反馈。第四题分别输入 3、2、8，依次看到「封条还在原孔」「两格是到右箱」「从左钩重新数」。再填 4 才能过题。末题两种错误摆法实际显示 6 对 8 和 8 对 4，后者特别点出「能抬箱子」与「刚好停平」的区别。实验与挑战均标为 G3–4，知识点沿用 G6 课内归属。[挑战与误区](../../content/activities/act.quiz.lever-dock-01/activity.yaml)

另核对了旧模块中分数专用零件。旧版的分数标记、表示整体的「1」框和数线只在骨架定义中互相引用，从杠杆画面或输入路径都到不了；新版杠杆已撤去这部分代码，仍保留实际使用的操作把手。

## Anatomy 七问

| 问题 | 实际看见或试出来的事 |
|---|---|
| 1. 盖住字，看得懂在演什么吗？ | 同一只大木箱始终吊在右侧，小铁环沿左侧木孔换位。第二站两处封钉仍在杆端，台面下的三角木换位；手里的动作也跟着换了。 |
| 2. 动手改变了哪个实物？ | 小环从第五到第七孔，木杆依次右低、平、左低。杆面每跨一段多一组压印，一环一枚，两环两枚。固定右箱只跨一个孔距，这一段挤着六枚；台面上两行把这些印排直，能用手指比较。 |
| 3. 挡住揭晓，还剩下怎样的惊讶？ | 隐去 SVG 文字，只截实物区。第六孔的箱底仍贴着放大窗里的粉笔印；第七孔能从两者中间看见一条空隙，同时远座的小人压低近座的大人。退回一孔，缝重新合上。390 宽的课程页内实测放大窗亮缝约 16 个 CSS 像素；像素只衡量能否看清。 [第六孔与第七孔](physics.machine.lever/chalk-comparison.webp) |
| 4. 拿走的东西属于孩子吗？ | 同一平板排版，甲留一环七格、近箱支点，乙留两环三格、居中支点。遮字后仍能认出甲图的上杆倾斜，乙图的双环在中间一带；下杆的支点和盘中砝码数量也不同。 [两次自选星卡](physics.machine.lever/print-comparison.webp) |
| 5. 哪一步有选择？末题还要判断什么？ | 两个瞬间找到后，可以挑想留下的任一挂法，也可以自己选第二站用哪档平衡收卡。末题还要从总共五格中留出右臂，再选左挂重；仅仅让重箱升起的摆法也会被判错。 |
| 6. 数怎么来的？ | 一环一牛、右箱六牛、等距孔和两档支点都是给定器材。依据水平轻杆两侧相反力矩相等的条件手算：一牛六格可托平，七格抬箱；锁钩后在中档为 6×3 对 6×3，近箱档为 3×4 对 6×2。 |
| 7. 有没有挡住、断开或挤出去的地方？ | 复拍的手机深色图能分清右箱底、背板与三角木，图上的号码、两钩封条和下方握把各有位置。平板与电脑减少动效时也能分辨两张拓印的挂法。[手机第二站](physics.machine.lever/sealed-phone.webp) · [平板动手画面](physics.machine.lever/bench-tablet.webp) |

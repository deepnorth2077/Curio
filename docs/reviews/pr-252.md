# PR #252 · 零件库 v1 两轮审查与验收

本记录合并了对 `e22bcb7` 的两份独立审查。仓库审查复现了订阅覆盖、版本冻结、原型收发和零件复用问题。附件 `review-pr252-r1.md` 通过变异检查发现，模块的静音、节流、非法色值和库 README 契约即使出错，当时的测试仍能通过。附件还指出数线旗子和巧克力包装纸在同一格内会反复响。

PR 前两次实现由 Antigravity 完成。第二轮修改与复核由 Codex 完成。工具、活动、宿主和浏览器走查分别在独立代理会话中核对，版本基准为 `8c4becd`。任务见 [#251](https://github.com/deepnorth2077/Curio/issues/251)，规格见 [零件库规格](../specs/kit.md)。

## 两份审查怎样落到验收

| 审查发现 | 修订与验证 |
| --- | --- |
| 活动订阅 `init` 或 `mute` 会关闭库的内建处理。普通 HTML、Canvas 也被迫提供站卡 DOM。 | 消息可有多位订阅者。普通活动用 `Kit.start(enter)` 接收初始化，选择站卡布局才挂载导航。验证含领航员、完成进度、隐藏提问、运行时切色和静音，以及迟到的初始化。 |
| 数学星卡需要重玩，生命星座需要继续下一站。共享的 SVG 与分数又依赖个别活动。 | 站卡可选提供 `resume(n)`，两种返回路径分别验证。整体「1」与数线的形状和文字样式随 kit 分发。验证零分子、三位数及超出中文数字表范围的可读名称，以及只载入 kit.css 时的深浅配色。 |
| 平台一改色，CI 就要求修改已冻结的 v1。最后一个活动迁走后，CI 又允许改 v1。宿主拒收合法新增色位。 | 按主线使用历史永久冻结库文件。新版本的后备色在发版前核对。冻结后宿主使用当前平台色，单独打开的旧活动使用发版时的后备色。测试从 v1 升 v2、迁走最后一个使用者、旧版字节篡改、增加第 21 色和 README 契约不符。 |
| 同步只认第一段 style/script，顺序颠倒会写坏 HTML。缺失的骨架标记可能被跳过。 | 直接定位标记所在的元素并按位置替换，测试多段脚本、顺序颠倒、缺标记和重复同步。 |
| 空活动因嵌入库的完成标记而取得讲解资格。只观察的实验又被强迫宣告预测。 | 只分析活动实际调用的事件和零件，区分顶层重声明、局部同名和不执行的示例。用空活动、仅观察、含预测和公开名冲突的正反样例核对发布条件。 |
| 外壳与活动各有一份合成器。播放中点静音关不掉后续琶音，新音效或重绘也可能重复播放。 | 最新 kit 的 `createSfx` 是同步原件，外壳导出同一份代码。静音会取消已排程的声音，点亮音移到结果状态变化处。对两端分别验证手势解锁、35 ms 节流、增益、回收，以及静音后开声不会重放。 |
| 包装纸、旗子和 starter 的连续移动会在同一格内频繁响，猜中时也只听到点击声。 | 拖动记录上一格，只在跨格时触发。猜中、未猜中使用各自声位。数线与巧克力的走查实际拖动控件，比较同格及跨格的声效计数。抓手使用圆钮配色。 |
| 正式宿主在完成写入期间会漏送偏好。预览只在进入时发配色，冻结原型收不到 1.2 的完成通知，数学试玩链接仍提供旧活动。 | 测试暂停完成写入时切换偏好。正式入口、试玩入口及原型按活动声明的契约通信。Pages 重建数学试玩页。用生成的内容包验证 1.1、1.2 的初始化和完成通知，以及打开中的 1.2 收到深浅和静音变更。 |
| 新的活动 ID 与第 5 站缺少声明途径。 | 1.2 的分站讲解模拟可在受校验的 manifest 声明 `station_count`，同一站数用于正式宿主、进度恢复及试玩入口。旧发布包仍可使用原站数登记。 |
| 杠杆手机走查曾在 `04-sealed` 之后滚动到已经重绘的 SVG 子元素。 | 改为滚动到稳定的画布，再取拖动位置。保留原有断言，手机单场复核通过。 |

## 家庭验收

1. 打开正式星图，先切到深色，再进「数线跳跳」。拖旗子时，在同一小格里挪动应当安静，跨过刻度才有一声。探索中切到浅色，确认卡片、按钮与外壳一起变。
2. 在「掰巧克力」里慢慢拉开包装纸，试试正确和错误的猜测。按声音开关时应当立即安静。完成后领取星卡，退出再进入，能选已完成的站重玩。
3. 从数学试玩页打开数线，再从原型打开同一活动。完成后都应出现接续入口。另开一颗原有 1.1 活动核对原来的玩法。

iPadOS 的真实扬声器、物理静音开关和主观音量留给真机试听。实现保留系统默认音频类别，并在触摸结束或点击时重试解锁。

## 自动化证据

- 在隔离副本中分别移除模块的十六进制检查、35 ms 节流与静音检查，三个变异都触发测试失败。
- Chromium 对模块与外壳的离线音频渲染，静音后的输出均为零。两个迁移活动在手机、平板、桌面三种尺寸，实际拖动都满足同格不响、跨一格响一次。
- 1.1 对照活动及 1.2 迁移活动均通过原型和试玩发布产物的握手与完成检查。七站预览用站号 5、7、8 验证恢复边界，只有 5、7 回到活动。
- 更新后的两颗活动完整走查共 283 项通过。数线 199 项，巧克力 84 项，两个活动的三端控制台均无警告或错误。

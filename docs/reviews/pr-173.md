# #173 站点记录的独立复核

独立验收者先按 event/2 的现有定义写摄入向量和恢复用例。实现前，第一个合法的站点观察被隔离，备份回放只接受开始和结束两条。实现后，用同一份期望值复核了 JavaScript 内核和 Python 备份参考实现。

- 接收数字、布尔值和不超过 32 个 Unicode 码点的字符串。缺字段、多余字段、数值越界、错误的记录者、重复和冲突均按既有摄入规则处理。
- 六条原始记录经过加密、解密、恢复事务、重放和导出，逐条一致。再次恢复只计重复。没有站点观察的旧备份仍可恢复。
- 观察本身没有挑战成绩。完成整个探索投影为「探索过」，点亮规则沿用现有挑战成绩。

核对文件为 `kernel/vectors/ingest-sim-observed.json`、`app/test/observation-backup.test.js` 和 `tools/tests/test_vectors.py`。独立验收由未参与内核实现的 Codex 子任务完成。

「生命的说明书」星座准备（三张知识点卡、领航员对话、内容任务模板）的外部审阅，重点是科学事实。

### 结论

**改完再合入。** 三张卡的绝大多数科学事实正确、适龄处理得当，但有两处「阻断」级问题会教给孩子（或被孩子自然追问出的）错误知识：① 成熟红细胞没有细胞核，却与「每个细胞都带着同一套说明书」的绝对表述矛盾；② 染色体卡「46 条配成 23 对，每对一条来自爸爸一条来自妈妈」紧接着「男孩 XY」时，会误导孩子推出「Y 来自妈」之类错误。另外教材章节层级标注需补全、误区有一处逻辑瑕疵。

### 其他问题

#### 1. 成熟红细胞与「每个细胞都有同一套说明书」的隐性矛盾
- 严重程度：**阻断**
- 位置：`biology.genetics.dna-intro.yaml` objectives 第 3 条 + `biology.cell.cell-intro.yaml` objectives 第 4 条（「一般都有细胞核」）
- 问题：DNA 卡说「几乎每个细胞都带同一套说明书」，但人成熟红细胞无核、无 DNA，是初中教材明确要学的内容。孩子从细胞卡到 DNA 卡会自然追问「红细胞呢」，将来讲血液时正面矛盾。
- 建议：把「几乎每个」改为明确表述并预留解释钩子；或在细胞卡「一般都有细胞核」处同步点出「红细胞是例外」。

#### 2. 「每对染色体一条来自爸一条来自妈」未交代性染色体的来源方向
- 严重程度：**重要**
- 位置：`biology.genetics.chromosome-intro.yaml` objectives 第 3、4 条 + G3-4 lens
- 问题：两句相邻，孩子会推出「Y 来自妈」或「X 来自爸」的错误；性别决定的真正机制（男 X 母 Y 父）反而被埋没。
- 建议：G3-4 镜头补一句「男孩的 X 来自妈妈、Y 来自爸爸；女孩两条 X，一条来自爸爸、一条来自妈妈」。

#### 3. 染色体卡的「像爸爸又像妈妈」解释跳过了基因
- 严重程度：**重要**
- 位置：`biology.genetics.chromosome-intro.yaml` G3-4 lens
- 问题：用「染色体一半来自爸一半来自妈」直接解释「像爸又像妈」，机制上漏掉「基因（DNA 说明书）才真正决定长相」。DNA 卡刚讲过「说明书」，此处应自然衔接为「基因（说明书的字）一半来自爸、一半来自妈」。
- 建议：改 lens 措辞，把「像」的机制落到基因而非染色体数目。

#### 4. 误区质量与遗漏
- 严重程度：**建议**
- 位置：三张卡的 `misconceptions`
- 问题与建议：
  - 细胞卡三条误区（only-animals / one-kind / visible）都是 8–10 岁真实误区，选得好。**遗漏**高频误区：**「细胞是死的/没有生命」**——孩子常以为细胞只是「身体里的小零件」。可补 `id: cells-are-dead`。
  - DNA 卡两条误区（blood-only / different-books）真实且经典。**遗漏**：**「DNA 只在父母传给下一代时才出现」**——孩子可能以为遗传物质只在「生育」时才相关，而非「随时指导身体生长」。可补一条。
  - 染色体卡四条误区（bigger-more / chromosome-is-gene / from-one-parent / same-in-boys-girls）中，`from-one-parent` 与正确表述之间的张力正好是教学抓手。缺一条**「染色体数量多 = 更高级/更聪明」**的误区（比「更大=更多」更贴近孩子价值观），可选补。

#### 5. 三颗星的顺序与粒度
- 严重程度：**建议**
- 位置：星座整体设计（细胞 → DNA → 染色体）
- 问题：顺序「细胞 → DNA → 染色体」整体合理（由可见到不可见、由容器到内容到包装），但中间**缺一个台阶**：孩子从「细胞」直接跳到「细胞核里的 DNA」时，缺少「细胞核」这一中介概念的正式介绍。
- 建议：或在细胞卡里强化「细胞核是细胞里最重要的『小房间』」，或在 DNA 卡 objectives 里显式加一条「知道细胞核是细胞里放说明书的地方」。三颗星不必拆成四颗，但要把「细胞核」台阶补实。

#### 6. `style: tutor` 设计与回退
- 严重程度：**建议**
- 位置：`docs/specs/content.md` 3.5 节
- 问题：把「领航员对话」设计为纯显示层、不改内容结构与判分，引擎不认识时按 `plain` 回退——这个设计**合理且稳健**，未发现会教错知识或卡流程的漏洞。
- 建议（仅细化）：① 明确 `feedback` 在 tutor 模式下由领航员「说」出时，是否仍受 3.7 节「不出现『学习』二字、≤60 字」约束；② 明确 `check` 在 tutor 模式下「提示阶梯照常可用」的交互入口，避免实现 AI 把 hint 做成纯文本堆叠。

#### 7. 知识点卡先合入 + 内容模板的漏洞
- 严重程度：**建议**
- 位置：`docs/workflow.md` 第 2 步、`prompts/content-template.md`
- 问题与建议：
  - 「先合入知识点卡（draft、activities 留空）」与「make_task.py 只读已合入内容」自洽。但「科学类知识点要求卡片和活动都再请另一个模型交叉核对」与「卡片先合入」之间，应明确**卡片合入前**是否已完成事实核对，避免出现「已合入但事实有误」的窗口期（本次审阅正是这个窗口）。建议在 workflow 第 2 步明确「事实核对意见在卡片合入 PR 里一并提交，或合入后立即补」。
  - 模板「怎么自己验证」里有「把每个科学事实和出处对一遍」，但「验收标准」三条里**没有**「科学事实与出处已核对」这一条。建议在「验收标准」加一条显式勾选框，防止实现 AI 编造或漏引出处。

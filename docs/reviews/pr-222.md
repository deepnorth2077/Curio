# 杠杆星复验：舰长何时需要线索

知识点 `physics.machine.lever` · [任务 #195](https://github.com/deepnorth2077/Curio/issues/195) · [PR #222](https://github.com/deepnorth2077/Curio/pull/222) · [单星试玩](../../prototype/preview/lever/index.html)

设计与整合由 Codex 主会话负责，动手与挑战分别由 Codex `pilot_ui`、`pilot_quiz` 实现。两次审查均由 Codex `pilot_review` 独立进行。三方使用同一类模型，分会话工作。

## 设计审查 · 通过

对照设计稿 `6eae86a` 和旧试玩 `3aa35db`。旧版在 360 px 深色下留下中档的印，再让两头各挂 6 牛，把支点朝箱子挪一格。封条文字的包围框越出台面顶边 0.48 CSS px，盘签和拓印的两个「6 牛」上下交叠 9.40 CSS px。孩子一拨支点就听到「试试从那头卸货」。

纸面验算得出两种拓印。两钩相隔六格，支点平分时两钩各需六牛；把支点往右挪一格，左边三牛就够。保留这两个档位，让孩子决定先改挂重还是先挪回支点。方向提示只在失衡时由孩子主动点开。第 1 题应让孩子亲自数一格和三格，两块砝码要看起来一样重，木杆要保持水平。第 5 题选「左边留 3 格，挂 2 牛」可以准确反馈六枚对八枚，仅凭这次选择无法判断孩子怎么想。按以上条件交付实现。

## 成品审查 · 通过

所审实现为 `993c3ca`。用 Chromium 从单星页面的「动手探索」和「挑战」进入，在 360、390 px 深色，768 px 浅色（减少动效）和 1280 px 深色各做完一轮。重建的单星 HTML 与仓库试玩文件逐字节相同。

首轮退回了第 1 题的深色插图。左侧 2 牛呈深色，右侧 2 牛呈浅色，孩子可能把颜色当作解题线索。修订后再从页面抽出题卡，分别打开深浅两张查看，砝码从吊钩、块面到标签均相同，左砝码与三角木也有空隙。[两种主题的第 1 题](lever-pilot/setup-question.webp)

| anatomy 七问 | 本轮实际观察 |
|---|---|
| 1. 看图能看懂什么？ | 开场木杆扣平，铁环和箱子各自垂下。第 2 站的钩头都有封条；活动把手在三角木正下方。 |
| 2. 动作改变了什么？ | 点左第 5、6、7 格，方印从五枚变六枚再变七枚，右侧始终六枚。第 2 站第一次失衡只问「哪头先低了？」左低时主动要线索会听到「从左盘取下一牛」，右低时会听到「给左盘添一牛」。平衡后按钮收起。 |
| 3. 遮住揭晓还能看见什么？ | 第 6 格时箱底盖着粉笔印，第 7 格露出整道带缺口的脚印，同时跷跷板出现。主箱的抬升很小，放大窗里的空隙最清楚。算式须主动点开才出现。[扣住、停平和抬起的三帧](lever-pilot/chalk-mark.webp) |
| 4. 孩子留下了什么？ | 分别拓了七格一环和三格两环。两张成品的铁环个数、绳子位置、杆的倾角都不同；第二幅的三角木与盘中砝码也随最终选档改变。[两次实玩所得的星卡](lever-pilot/chosen-prints.webp) |
| 5. 末题还要新判断什么？ | 玩过的是六格间距；末题把两钩改成五格。选择左边三格两牛，看到左六枚、右八枚；选择四格两牛，看到八对四；选择四格一牛，得到四对四。页面从题干到选项均用格距，第一项的题库记录已去掉错因标签。 |
| 6. 数字从哪里来？ | 水平松手比较两边的力×格数。第 1 题是 2 对 6，第 2 题是 5 对 6，第 3 题是 10 对 6。第 2 题题面和改错反馈只谈左钩和右钩。第 4 题填 3、2 各得到对应反馈，填 4 通过。360 px 先选错再改完成五题，390 px 一次答对五题。 |
| 7. 小字和实物分得开吗？ | 重走旧版相同动作，360 px 封条顶端距台边 13.36 CSS px，两个「6 牛」相隔 16.07 CSS px。390 px 分别为 14.71 和 17.97 CSS px。两档都已拓印后又向左右倾斜，两条重量字也保持分离。[窄屏同一动作的修前与修后](lever-pilot/narrow-before-after.webp) · [平板与桌面的封钩台](lever-pilot/tablet-desktop.webp) |

390 px 触屏手势从第 1 孔一口气拖到第 7 孔，松手后看见脚印，此时仍不能拓杆；回点第 6 孔停稳，才出现「拓下这根杆」。在 360 px 成品星卡里「再玩第二站」再收一次，宿主总共收到一次预测、两次分站观察、一次完成。舰长是否会自己在第 6、7 格之间反复对照、是否觉得领航员的钉子台词好笑，留给真人试玩判断。

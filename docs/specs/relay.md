# 规格：AI 中转服务和连通测试（#31 第一段）

- 状态：提议，第 2 稿（2026-11-09：中转放云上、每家一份、首批只做腾讯云；等跨模型外部审阅）
- 依据：ADR-010（云上的小后端）、AGENTS.md 原则 5（AI 只走网关）、事件规格第 1 节（本地日期按 UTC+8）、`docs/constellations/life-manual.md`（领航员的说话方式）
- 实现任务：#31 拆成两段（拆法等 Luka 确认）：
  - **第一段（本规格）**：中转服务、部署手册、指挥中心的连通测试和用量。演示：家长在指挥中心点「连通测试」成功，点「试问一个问题」几秒内收到领航员的回答，用量数字跟着变。不依赖 #25。
  - **第二段**：舰长在领航员对话里随时提问，问答存成私人文字和事件，进信号站，可以标记「这个回答好像不对」。等 #25（领航员对话）之后另写规格。

## 问题

孩子想问「为什么」的时候，平台现在只能把问题记下来，等家长回答。接 AI 必须有地方放 DeepSeek 的密钥：放在页面里，孩子的设备上就能翻出来，谁拿到都能花钱。这个地方放在云上（ADR-010），并且**每家一份**：以后别的家庭照同一份手册，在自己的云账号里部署自己的中转、用自己的密钥。

## 方案

云上一个很小的中转服务：页面带着家庭口令请求它，它检查口令和上限，再带着自己保管的密钥去问 DeepSeek，把回答交回页面。花费有三道闸。代码一份，首批部署到腾讯云云函数；处理函数不绑平台，以后加别的平台只多一个薄适配层。部署好以后在孩子的设备上跑连通测试。

## 用户故事

1. 作为家长（包括以后别的家庭），我想要照着手册复制粘贴就能在自己的云账号里部署好中转服务，这样不用会写代码，也不用把密钥交给别人。
2. 作为家长，我想要在孩子的平板上点一下就知道中转服务通不通、快不快，这样部署完就知道能不能用。
3. 作为家长，我想要 AI 一个月最多花多少钱由我定，到了就停，这样不会有意外账单。
4. 作为家长，我想要在指挥中心看到这个月问了几次、花了多少，这样心里有数。
5. 作为家长，我想要别人拿到页面也用不了我的额度，这样密钥和余额是安全的。
6. 作为舰长，我想要问了问题几秒内得到听得懂的回答，不确定的地方领航员会直说，这样我能相信它。
7. 作为维护者，我想要中转服务的规则能在 Node 里不联网测完，并且有手算的验收用例，这样换平台、改上限都有把握。

## 实现上的决定

### 1. 目录

```
relay/
  src/handler.js        handle(request, env, deps) → Response：全部规则都在这里
  src/navigator.js      领航员说明（system prompt）和回答的长度约束
  adapters/tencent.js   腾讯云 Web 函数的入口：把平台的请求转成标准 Request，存储用 COS
  test/                 node:test 测试，含验收用例
  DEPLOY.md             部署手册（给 Luka，每一步写点哪里、看到什么）
```

- JavaScript ES 模块，不引入依赖，不打包（ADR-008）。平台适配层只做转换，不含规则。首批只有腾讯云的适配层；以后要加 Cloudflare 等平台，只加一个 `adapters/<平台>.js`。
- `deps` 把外部依赖都传进来：`deps.storage`（`get(key) → string | null`、`put(key, string)`）、`deps.upstream(body) → {status, json}`（调用 DeepSeek）、`deps.now() → 毫秒时间戳`。测试时换成内存版本，不联网、不读时钟。

### 2. 配置（平台的环境变量）

| 变量 | 说明 | 默认 |
| --- | --- | --- |
| `DEEPSEEK_API_KEY` | DeepSeek 密钥。只在这里 | 必填 |
| `DEEPSEEK_MODEL` | 模型名 | 部署手册里写当时的名字 |
| `CURIO_PASSPHRASE_HASH` | `sha256(盐 + 家庭口令)` 的十六进制小写 | 必填 |
| `CURIO_SALT` | 盐，随机字符串 | 必填 |
| `CURIO_ALLOWED_ORIGINS` | 允许跨域的来源，逗号分隔。别的家庭用同一个公开网页时不用改；自己另外托管网页的，填自己的地址 | `https://deepnorth2077.github.io` |
| `CURIO_DAILY_CALLS` | 每天最多几次（本地日期，UTC+8） | 30 |
| `CURIO_MONTHLY_FEN` | 每月最多花多少分（本地月份，UTC+8） | 2000（20 元） |
| `CURIO_PRICE_FEN_PER_M` | 单价，「分 / 百万 token」，三个整数用逗号分开：未命中缓存的输入、命中缓存的输入、输出 | 部署手册里写当时的价格 |

部署手册附一个本地小网页（单文件，不联网），输入盐和口令算出哈希，Luka 把结果粘进平台设置。口令本身不进任何平台。

### 3. 接口

全部是 JSON。每个响应都带 CORS 头：请求的 `Origin` 在 `CURIO_ALLOWED_ORIGINS` 里时，回 `Access-Control-Allow-Origin: <那个来源>`；`OPTIONS` 预检回 204。

| 接口 | 口令 | 说明 |
| --- | --- | --- |
| `GET /v1/ping` | 不要 | 回 `{"service": "curio-relay", "version": 1}`。连通测试用 |
| `POST /v1/capabilities/tutor.ask` | 要 | 问一个问题，见下 |
| `GET /v1/usage` | 要 | 回本月用量，见下 |

**口令**放在请求头 `Authorization: Bearer <家庭口令>`。中转服务算 `sha256(盐 + 口令)`，和 `CURIO_PASSPHRASE_HASH` 做定长比较。

**`tutor.ask` 请求**：

```json
{"question": "为什么我的眼睛像妈妈？", "age_band": "G3-4", "context": {"node_title": "染色体", "activity_title": "把说明书卷好收起来"}}
```

- `question`：去掉首尾空白后 1～200 个字符（按 Unicode 码点数）；`age_band` 是 `G1-2`、`G3-4`、`G5-6`、`G7-9`、`G10-12` 之一；`context` 可选，两个字段各最多 40 个字符。不满足 → 400 `{"error": "bad_request"}`。

**成功的响应**：

```json
{"answer": "……", "usage": {"calls_today": 3, "daily_calls": 30, "fen_month": 1, "monthly_fen": 2000}}
```

`fen_month` 是本月已花的分数，向上取整。

**错误**：

| 状态 | `error` | 什么时候 |
| --- | --- | --- |
| 400 | `bad_request` | 请求格式不对 |
| 401 | `bad_passphrase` | 口令不对（计一次失败） |
| 429 | `locked` | 被锁定中（口令对也一样） |
| 429 | `daily_cap` | 今天的次数用完 |
| 429 | `monthly_cap` | 本月的花费到了上限 |
| 502 | `upstream` | DeepSeek 出错或超时（15 秒）|

页面按 `error` 显示给孩子能懂的话，例如 `daily_cap`：「今天的问题问完啦，明天再来，或者请家长调高额度。」

**`GET /v1/usage`**：

```json
{"month": "2026-11", "calls_by_day": {"2026-11-07": 3}, "fen_month": 1, "daily_calls": 30, "monthly_fen": 2000}
```

### 4. 规则（按顺序判断）

一个 `tutor.ask` 请求进来：

1. 格式不对 → 400。不计失败、不计次数。
2. **锁定**：存储里记着最近的失败时间（最多保留 10 个）。已有 10 个，并且最早那个距现在不到 3600 秒 → 429 `locked`。
3. **口令**不对 → 记下这次失败的时间（只保留最近 10 个）→ 401。口令对 → 清空失败记录。
4. **今天的次数**（UTC+8 的本地日期）已经 ≥ `CURIO_DAILY_CALLS` → 429 `daily_cap`。
5. **本月花费**已经 ≥ `CURIO_MONTHLY_FEN` → 429 `monthly_cap`。
6. 调用 DeepSeek（`max_tokens` 400）。失败或超时 → 502，不计次数；如果 DeepSeek 回了用量，花费照记。
7. 成功：今天的次数加一，按用量加上花费，存回存储，回答交给页面。

`GET /v1/usage` 同样先查锁定和口令（第 2、3 步），通过后回用量，不计次数。

**花费**用整数算，单位是「百万分之一分」：

```
花费 = 未命中缓存的输入 token × 单价1 + 命中缓存的输入 token × 单价2 + 输出 token × 单价3
```

单价的单位是「分 / 百万 token」，所以乘出来正好是百万分之一分。本月累计存成这个单位的整数；比较上限时用 `累计 ≥ 上限分 × 1000000`；给页面看的 `fen_month` 是 `累计 ÷ 1000000` 向上取整。DeepSeek 的用量字段：`prompt_cache_miss_tokens`、`prompt_cache_hit_tokens`、`completion_tokens`；前两个缺的时候，把 `prompt_tokens` 全部算作未命中。

**存储里的两个文件**：`usage/<YYYY-MM>.json`（`{calls_by_day: {日期: 次数}, cost_ufen: 整数}`），`auth/failures.json`（`{times: [毫秒时间戳…]}`）。新的月份就是新文件，旧的保留，家长以后想看历史也能看。

**并发**：读改写之间不加锁。一个孩子几乎不会同时发两个问题；万一同时发，最多多花一两次的钱，由 DeepSeek 预充值兜底（ADR-010 第 5 条）。

### 5. 领航员说明

`navigator.js` 里的 system prompt 要点（措辞由 Claude 在派发时写定，照 `life-manual.md` 的领航员说话方式）：

- 你是好奇号的领航员，对面是舰长（一个 `age_band` 年龄段的孩子），叫他「舰长」。
- 用这个年龄能懂的话，句子短，一次回答不超过 150 个字；能举身边的例子就举。
- 不确定、或者科学上还没有定论的，直接说「这个我也不确定」或「科学家还在研究」，不编造。
- 不出现「学习」二字。不问孩子的名字、住址、学校。
- 涉及危险、身体不舒服、和别人起冲突、或者不适合孩子的问题：不给具体做法，请舰长去找家长。
- 最后可以抛一个「你可以自己试试看」的小问题。

`context` 有的时候，告诉领航员舰长正在看哪颗星、哪个活动。

### 6. 指挥中心（原型里先做，正式外壳随第二段）

设置里的「AI 答疑」卡片（已有地址、口令、每日上限三栏）加上：

- **连通测试**：对 `GET /v1/ping` 连续请求 5 次，每次最多等 5 秒，显示「成功 X/5，平均 Y 毫秒」。全部失败时提示「连不上：检查地址，再看部署手册的『常见问题』」。
- **试问一个问题**：用固定的问题「天空为什么是蓝色的？」调用 `tutor.ask`，显示回答和用量。
- **用量**：调用 `GET /v1/usage`，显示本月每天的次数和花费。
- 页面上的「每天最多问几次」只是显示用，真正的上限在中转服务的设置里，卡片上要写明这一点。

### 7. 部署手册（`relay/DEPLOY.md`）

写给任何一个家庭（不只是 Luka），每一步写明：打开哪个网址、点哪里、粘贴什么、应该看到什么。包括：给 DeepSeek 充值（建议第一次只充 50 元）、在 DeepSeek 后台建密钥、算口令哈希、部署函数、填环境变量、打开腾讯云对象存储 COS 并开启版本保留、拿到地址、填进好奇号的设置、跑连通测试。最后写「怎么改上限」「怎么换密钥」「常见问题」。手册里不出现任何一个家庭的地址、口令或密钥。

## 测试接缝

| 接缝 | 能发现 | 发现不了 |
| --- | --- | --- |
| `handle(request, env, deps)` + 内存存储 + 假的 DeepSeek + 固定时钟 | 口令、锁定、两种上限、花费算法、日期和月份按 UTC+8 切换、错误码、CORS、请求校验、不存原文 | 平台适配层、真实网络 |
| 部署后的 `GET /v1/ping` 和「试问一个问题」 | 部署对不对、环境变量填没填、网络通不通 | 规则细节 |
| 让一个没参与制作的人（或子 agent）只看 `DEPLOY.md` 走一遍 | 手册有没有漏步骤、写得是不是不懂代码也能照做 | 平台控制台以后改版 |

**验收用例**（Claude 手算，派发时写成 `relay/test/cases.json`，这里列关键几条）：

| 情况 | 期望 |
| --- | --- |
| 单价 `200,20,800`；一次用量：未命中 1000、命中 500、输出 300 | 花费 = 1000×200 + 500×20 + 300×800 = 450000 百万分之一分；`fen_month` = 1 |
| 上限 2000 分，累计 1999999999 | 还能再问一次（< 2000000000）；问完累计 ≥ 上限，下一次 429 `monthly_cap` |
| 每天 30 次，今天已经 30 次 | 429 `daily_cap`；本地时间第二天 00:00（UTC 16:00）起恢复 |
| UTC 2026-11-30T15:59:59.999Z 和 2026-11-30T16:00:00.000Z 各问一次 | 分别记进 `usage/2026-11.json` 和 `usage/2026-12.json` |
| 口令连错 10 次，第 10 次在 t | t 之后、最早那次 +3600 秒之前，口令对也回 429 `locked`；之后恢复 |
| 口令连错 9 次，第 10 次对 | 200，失败记录清空 |
| DeepSeek 回 500，没有用量 | 502，次数和花费都不变 |
| `question` 是 201 个汉字 | 400；不计失败、不计次数 |
| `Origin` 不在允许名单 | 正常处理，但响应里没有 `Access-Control-Allow-Origin` |
| 任何请求之后 | 存储里找不到问题和回答的原文 |

## 不做什么

- 舰长在领航员对话里提问、存私人文字和事件、标记回答不对：第二段。
- 同步和备份：CURIO-008，方向见 ADR-010 第 7 条。
- 拍照识题、举一反三：以后各自定规格，沿用 `/v1/capabilities/<能力名>`。
- 两个模型交叉核对：Luka 2026-11-06 决定先不做。
- 几个家庭共用一个中转、在中转里区分家庭：不做（ADR-010 第 2 条）。
- Cloudflare 等别的平台的适配层：等有需要再加。
- 流式输出：回答很短，一次给完。

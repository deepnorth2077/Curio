# 恢复演练手册（每季度一次）

照 `docs/specs/backup.md` 第 12 节写的。一共六步，大约 15 分钟。

要准备：

- 平时用的 **iPad**。
- 一台**电脑**。
- 一支笔、两张纸。
- 网址：https://deepnorth2077.github.io/Curio/app/

## 第 1 步：在 iPad 上做两次挑战

**打开**：iPad 的 Safari，打开上面的网址。

**点哪里**：

1. 点一颗星，认真做完。目标是让它亮起来（第一次就答对大部分）。
2. 再点另一颗星，随便答，让它**不亮**。
3. 在第二次挑战里，答错一次以后，点一次「看答案」。

**应该看到**：

- 星图上一颗星是亮的（金色），一颗是半亮的。
- 做完回到星图，星星还是这个样子。

## 第 2 步：在 iPad 上做恢复密钥和备份

**打开**：星图页最下面，有一行小字「家长」。点它。

**点哪里**：

1. 点「做一份备份」。
2. 屏幕上出现 6 个大大的数字，像 `482 105`。
   - 把它抄在**两张**纸上，放在两个地方。
   - 想打印也可以，点「打印」。
3. 点「抄好了」。
4. 把键盘切到**中文输入法**（拼音），看着纸，把 6 个数字输一遍。中间带不带空格都行。点「确定」。
5. 等几秒，出现「备份做好了」。
6. 把文件存好，两种办法选一种：
   - 点「下载备份文件」。Safari 问要不要下载，点「下载」。文件会在「文件」App 的「下载」里。
   - 或者点「存到文件或网盘」，选「存储到"文件"」或你的网盘。
7. 抄下这一页上的「指纹」，像 `3fa9 c021`（8 个字母和数字）。
8. 点「回到家长页」。

**应该看到**：

- 第 4 步输错时，提示「和刚才的不一样，请对照纸上再看看」。点「回去再看」能再看到那 6 个数字。
- 家长页写着「上次备份：今天」。
- 家长页写着「记录 N 条 · 指纹 ……」，指纹和你抄的一样。

**再做一件事**：把备份文件送到电脑上。可以用「隔空投送」，或者先存进自己的网盘，再在电脑上下载。
备份文件请存在只有你能打开的地方。不要发到群里，不要放进公开的分享链接。

## 第 3 步：在电脑上恢复

**打开**：电脑上一个**从来没打开过 Curio 的浏览器**。最简单的办法：

- Chrome：点右上角的头像 →「添加」→ 新建一个个人资料，用这个新的窗口。
- 或者用电脑上另一个从来没用过的浏览器。

在这个窗口里打开上面的网址。

**点哪里**：

1. 星图上的星星都是暗的。下面有一句「以前在别的设备上用过？请家长从备份恢复」。点它。
2. 在「从备份恢复」里：
   - 「选备份文件」：选 iPad 上做的那个文件。
   - 「输入恢复密钥」：输纸上的 6 个数字。
3. 点「读备份」。等几秒。
4. 看到「要恢复的备份」，上面写着备份是哪天做的、「新的记录 N 条」。点「恢复」。
5. 看到「恢复好了」。点「好」。

**应该看到**：

- 页面重新打开，还是家长页。
- 「记录 N 条 · 指纹 ……」：条数和指纹都和 iPad 上**一样**。
- 点左上角「星图」：亮的星、半亮的星，和 iPad 上一样。

## 第 4 步：在电脑上再恢复一次同一个文件

**打开**：还是电脑上那个窗口，家长页。

**点哪里**：

1. 点「从备份恢复」。
2. 选**同一个**文件，输**同一个**密钥，点「读备份」。
3. 看到「要恢复的备份」，点「恢复」，再点「好」。

**应该看到**：

- 「要恢复的备份」上写着「新的记录 0 条」「重复 N 条」。
- 恢复好以后，指纹**没变**，星星也没变。

## 第 5 步：故意弄错两次

**打开**：还是电脑上的家长页，点「从备份恢复」。

**点哪里**：

1. 选那个备份文件，密钥故意**改错一个数**，点「读备份」。
2. 找一张照片，复制一份，把名字改成 `照片.curio`（改不了名字的话，直接选那张照片也行）。选它，输对的密钥，点「读备份」。

**应该看到**：

- 第 1 次：「恢复密钥不对。请对照纸上的密钥再输一次」。
- 第 2 次：「这不是 Curio 的备份文件」。
- 两次以后，家长页上的指纹都**没变**。

## 中途断了怎么办

恢复的时候关了页面、断了网、浏览器出错，下次打开会看到「上次恢复没做完」和两个按钮：

- 「再恢复一次」：选**同一个**备份文件，输密钥，照第 3 步做完。选别的文件会提示「上次恢复的是另一个备份……」。
- 「不恢复了，就用现在这些」：已经恢复进去的留着，设备照常能用。

两个都不会弄坏记录。

## 密钥纸条丢了怎么办

两张纸都找不到了，也还有办法：用你**自己的一个备份文件**，在电脑上把 6 个数字一个一个试回来。

- 要多久：一台普通的电脑，几个小时到一天多。电脑核越多越快。
- 不联网，只读你给它的那个文件，别人看不到。
- 需要：电脑上装好 Python 3，下载 Curio 仓库，再装一次 `cryptography`。不会装的话，请 Claude 帮你一步一步来。

在 Curio 仓库的文件夹里，打开终端，输入：

```
pip install cryptography
python tools/recover_key.py 你的备份文件.curio
```

它会每隔一会儿说一句试到哪里了、大约还要多久。找到了会说：

```
找到了。恢复密钥是 482 105
```

把它抄在两张纸上，放好。

小提示：

- 中途想停，按 `Ctrl` + `C`。下次从停下的地方接着试，例如从 300000 开始：`python tools/recover_key.py 你的备份文件.curio --from 300000`。
- 两台电脑可以分着试：一台试 `--from 0 --to 499999`，另一台试 `--from 500000 --to 999999`。
- 这件事说明了一点：**拿到备份文件的人，也能这样试出密钥**。所以备份文件一定要存在只有你能打开的地方。

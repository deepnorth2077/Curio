# 通用任务提示词模板

Claude 用这个模板写所有「非活动模块」任务的提示词，比如平台功能、工具、修复。活动模块（讲解、挑战、实验）用 `prompts/module-template.md`。

写法：
- 复制本文件，把 `{{…}}` 换成具体内容，存为 `prompts/<任务 id>.md`，同时贴进 issue 的「提示词」一节。
- 提示词必须**自成一体**：实现 AI 看不到仓库。需要的规格、已有代码、接口，都直接贴进来，不要写「见某某文件」。
- 修改 `docs/submission.md` 时，所有模板里嵌入的交付包格式要同步更新。
